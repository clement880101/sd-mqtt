# The Listener Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put the broker on a socket. A tokio runtime, a TCP listener, one task per connection, a ticker, graceful shutdown, and the `sdmqtt` binary. Then prove it against an independent conformance suite.

**Architecture:** Deliberately thin. Everything hard is already built and tested without I/O; this layer reads bytes, hands them to the broker, and writes what comes back. If you find yourself making a protocol decision here, it belongs in `broker-core`.

**Tech Stack:** tokio for the runtime and sockets, `bytes` for the read buffer, `clap` for the command line, `toml` and `serde` for configuration, `tracing` for logs.

**Spec:** `docs/superpowers/specs/2026-09-19-sd-mqtt-design.md`, sections 4, 10.1 and 16. This plan completes milestone one.

---

## Read first

`docs/conventions.md`. It is short, and it is the rules this project works by with the specific failure that earned each. Convention 5, about tests that cannot fail, has seven recorded instances and has produced a real bug in every plan so far.

Three obligations inherited from the layers below are listed in the broker plan. The one that bites hardest here is the last: **a caller that receives an error from the broker must call disconnect, not merely close the socket.** Otherwise the session believes it is still attached, never expires, and never fires its will.

---

## The one thing this plan knowingly gets wrong

The broker's methods take `&mut self`, so the shell serialises every packet through a single lock. At the connection counts the design targets that is the defining bottleneck, and it undoes the sharding the subscription trie does internally.

**This plan does not fix it.** It measures it, in task 8, so the number exists before anything is redesigned around a guess. Twice on this project the obvious optimisation turned out slower when measured: hoisting interner lookups under one guard cost thirty percent, and boxing a hot-path packet would have traded a move for an allocation. A third guess is not wanted.

What the plan does require is that the lock is held for as short a span as possible and never across an await, so that the measurement is of the real design rather than of an accident.

---

## Why three tasks give a contract rather than code

Tasks 1, 2 and 4 supply complete code, as every plan in this project has.
Tasks 3, 5 and 6 supply the tests, the sequence and the reasoning, but
not the body.

That is deliberate and it is a judgement about where plan code has
helped and where it has hurt. Complete code has been worth it wherever
the plan could state the logic exactly: the codec, the trie, the state
machines. It has cost real bugs wherever the plan was guessing at
signatures it could not see, most seriously when a resume rule omitted
the packet identifier and broke exactly-once delivery.

The connection, the listener and the binary are mostly glue between
signatures from four crates, and a confident guess at them would be
wrong in ways the tests would then be written around. So those tasks
pin the behaviour and leave the wiring to someone who can read the real
signatures.

```rust
use std::collections::HashMap;
use std::sync::atomic::{AtomicU64, Ordering};

use broker_core::broker::{Addressed, Broker, BrokerConfig};
use broker_core::session::Action;
use broker_core::subscriptions::SubscriberId;
use foldhash::fast::RandomState;
use parking_lot::{Mutex, RwLock};
use tokio::sync::mpsc;

/// The broker, and where to send what it produces.
///
/// The broker's methods take an exclusive reference, so every packet in
/// the process passes through one lock. At the connection counts this
/// design targets that is the bottleneck, and it undoes the sharding the
/// subscription trie does internally. It is measured rather than guessed
/// at: see the benchmark in this crate. What matters until then is that
/// the lock is held for the shortest possible span and **never across an
/// await**, so the number measures the design rather than an accident.
pub struct Shared {
    broker: Mutex<Broker>,
    outboxes: RwLock<HashMap<SubscriberId, mpsc::Sender<Action>, RandomState>>,
    dropped_for_slow_reader: AtomicU64,
}

impl Shared {
    /// A server with no connections.
    pub fn new(config: BrokerConfig) -> Self {
        Self {
            broker: Mutex::new(Broker::new(config)),
            outboxes: RwLock::new(HashMap::with_hasher(RandomState::default())),
            dropped_for_slow_reader: AtomicU64::new(0),
        }
    }

    /// Do something with the broker, holding the lock for exactly that.
    ///
    /// The closure must not await and must not block. Anything slow
    /// belongs outside it.
    pub fn with_broker<T>(&self, f: impl FnOnce(&mut Broker) -> T) -> T {
        let mut broker = self.broker.lock();
        f(&mut broker)
    }

    /// Claim the outbox for a session, returning the receiving half.
    ///
    /// A handle names a session rather than a connection, so a takeover
    /// registers a second outbox under the same handle. The newcomer
    /// replaces the incumbent, whose receiver then sees the channel
    /// closed, which is how its task learns it has been displaced.
    pub fn register_outbox(&self, subscriber: SubscriberId, depth: usize) -> mpsc::Receiver<Action> {
        let (sender, receiver) = mpsc::channel(depth);
        self.outboxes.write().insert(subscriber, sender);
        receiver
    }

    /// Forget a session's outbox.
    pub fn remove_outbox(&self, subscriber: SubscriberId) {
        self.outboxes.write().remove(&subscriber);
    }

    /// Send each action to the session it is addressed to.
    ///
    /// Never blocks. A session whose outbox is full has a reader slower
    /// than its traffic, and waiting here would stall every other
    /// connection behind it. The drop is counted rather than silent.
    pub fn deliver(&self, actions: Vec<Addressed>) {
        if actions.is_empty() {
            return;
        }
        let outboxes = self.outboxes.read();
        for (subscriber, action) in actions {
            let Some(sender) = outboxes.get(&subscriber) else {
                // The session went away between the broker producing this
                // and us delivering it. Ordinary, not an error.
                continue;
            };
            if sender.try_send(action).is_err() {
                self.dropped_for_slow_reader.fetch_add(1, Ordering::Relaxed);
            }
        }
    }

    /// How many sessions have an outbox.
    pub fn outbox_count(&self) -> usize {
        self.outboxes.read().len()
    }

    /// How many actions were discarded because a reader could not keep up.
    pub fn dropped_for_slow_reader(&self) -> u64 {
        self.dropped_for_slow_reader.load(Ordering::Relaxed)
    }
}
```

```rust
            .await
            .unwrap();

        let packet = reader.next(Version::V311).await.unwrap().expect("a packet");
        assert_eq!(packet, Packet::PingReq);

    async fn reassembles_a_packet_split_across_writes() {

        let (mut client, server) = duplex(1024);
        let mut whole = BytesMut::new();
        for _ in 0..3 {
            encode(&ping(), Version::V311, &mut whole).unwrap();

        let mut reader = FrameReader::new(server, Limits::default());
        let handle = tokio::spawn(async move {
            for byte in whole.to_vec() {
                tokio::io::AsyncWriteExt::write_all(&mut client, &[byte])
                    .await
                    .unwrap();
                tokio::task::yield_now().await;

        for _ in 0..3 {
            assert_eq!(
                reader.next(Version::V311).await.unwrap(),
                Some(Packet::PingReq)

        }
        handle.await.unwrap();
    }

    async fn a_clean_close_ends_the_stream() {
```

```rust
use bytes::BytesMut;
use mqtt_codec::{decode, CodecError, Limits, Packet, Version};
use thiserror::Error;
use tokio::io::{AsyncRead, AsyncReadExt};

/// Why reading a packet failed.
#[derive(Debug, Error)]
pub enum FrameError {
    /// The peer sent something that is not a valid packet.
    #[error("protocol error: {0}")]
    Protocol(#[from] CodecError),
    /// The connection failed, or ended partway through a packet.
    #[error("connection error: {0}")]
    Io(#[from] std::io::Error),
}

/// How much to read from the socket at once.
///
/// Large enough that a burst of small packets costs one syscall, small
/// enough that a hundred thousand idle connections do not each hold a
/// page they are not using.
const READ_CHUNK: usize = 4096;

/// Reads whole packets from a byte stream.
///
/// The codec does the hard part: it consumes nothing when a frame is
/// incomplete, and rejects an oversized one from its declared length
/// before any body arrives. This loop must not defeat either property by
/// buffering first and asking later.
pub struct FrameReader<R> {
    inner: R,
    buffer: BytesMut,
    limits: Limits,
}

impl<R: AsyncRead + Unpin> FrameReader<R> {
    /// A reader over `inner`.
    pub fn new(inner: R, limits: Limits) -> Self {
        Self {
            inner,
            buffer: BytesMut::with_capacity(READ_CHUNK),
            limits,
        }
    }

    /// The next packet, or nothing when the peer closed cleanly.
    ///
    /// A close partway through a packet is an error rather than an end:
    /// reporting a truncated stream as a clean one would hide a fault.
    pub async fn next(&mut self, version: Version) -> Result<Option<Packet>, FrameError> {
        loop {
            // Try the buffer first, so several packets in one read are
            // all returned without touching the socket again.
            if let Some(packet) = decode(&mut self.buffer, version, &self.limits)? {
                return Ok(Some(packet));
            }

            self.buffer.reserve(READ_CHUNK);
            let read = self.inner.read_buf(&mut self.buffer).await?;
            if read == 0 {
                if self.buffer.is_empty() {
                    return Ok(None);
                }
                return Err(FrameError::Io(std::io::Error::new(
                    std::io::ErrorKind::UnexpectedEof,
                    "the connection ended partway through a packet",
                )));
            }
        }
    }
}
```

```rust
//! One connection, from its first packet to its last.

#[cfg(test)]
mod tests {
    use super::*;
    use broker_core::broker::BrokerConfig;
    use bytes::BytesMut;
    use mqtt_codec::packet::{ConnAck, Connect};
    use mqtt_codec::{decode, encode, Limits, Packet, Properties, QoS, ReasonCode, Version};
    use std::sync::Arc;
    use std::time::Duration;
    use tokio::io::{AsyncReadExt, AsyncWriteExt};

    fn connect(client_id: &str, keep_alive: u16) -> Connect {
        Connect {
            version: Version::V5,
            client_id: client_id.into(),
            clean_start: true,
            keep_alive,
            username: None,
            password: None,
            will: None,
            properties: Properties::default(),
        }
    }

    /// Drive one connection over an in-memory socket, returning the
    /// client's half so a test can write packets and read replies.
    fn serve_one(shared: Arc<Shared>) -> tokio::io::DuplexStream {
        let (client, server) = tokio::io::duplex(8192);
        tokio::spawn(async move {
            let _ = serve(server, shared, ConnectionConfig::default()).await;
        });
        client
    }

    async fn write(client: &mut tokio::io::DuplexStream, packet: &Packet, version: Version) {
        let mut buf = BytesMut::new();
        encode(packet, version, &mut buf).unwrap();
        client.write_all(&buf).await.unwrap();
    }

    async fn read(client: &mut tokio::io::DuplexStream, version: Version) -> Packet {
        let mut buf = BytesMut::new();
        loop {
            if let Some(packet) = decode(&mut buf, version, &Limits::default()).unwrap() {
                return packet;
            }
            let mut chunk = [0u8; 1024];
            let n = tokio::time::timeout(Duration::from_secs(2), client.read(&mut chunk))
                .await
                .expect("a reply arrives")
                .unwrap();
            assert_ne!(n, 0, "the connection closed instead of replying");
            buf.extend_from_slice(&chunk[..n]);
        }
    }

    #[tokio::test]
    async fn a_connect_is_acknowledged() {
        let shared = Arc::new(Shared::new(BrokerConfig::default()));
        let mut client = serve_one(Arc::clone(&shared));

        write(&mut client, &Packet::Connect(Box::new(connect("c", 0))), Version::V5).await;
        match read(&mut client, Version::V5).await {
            Packet::ConnAck(ack) => {
                assert_eq!(ack.reason, ReasonCode::Success);
                assert!(!ack.session_present, "a clean start resumes nothing");
            }
            other => panic!("expected an acknowledgement, got {other:?}"),
```

- [ ] **Step 4: Write the implementation**

Write `connection.rs` to satisfy the tests and the specification answers
from step 1. The shape, which you should follow:

- A `ConnectionConfig` carrying the codec limits, the outbox depth, how
  long to wait for the first packet, our own receive maximum, and the
  mountpoint this listener namespaces its clients into.
- `serve(socket, shared, config)`, which:
  1. Reads the first packet with a timeout, and closes without a reply if
     it is anything but a connect. There is no session yet and nothing to
     address a reason to.
  2. Takes the version from the connect packet, since it is not known
     before.
  3. Assigns an identifier when the client sent none, and remembers to
     report it.
  4. Calls the broker's connect under the lock, taking the registration
     and any actions, then releases the lock before writing anything.
  5. Registers the outbox **after** the broker call, so a takeover's
     close reaches the incumbent's outbox rather than the newcomer's.
  6. Sends the acknowledgement, carrying what step 1 determined.
  7. Narrows the session's inflight window to the client's receive
     maximum, and sets the session's own receive maximum to ours.
  8. Splits the socket and spawns a writer task draining the outbox.
  9. Loops on the frame reader, handing each packet to the broker and
     delivering what comes back.
  10. On any exit, including an error, calls the broker's disconnect and
      removes the outbox. **This is not optional**: it is the inherited
      obligation, and a session left attached never expires and never
      fires its will. Structure it so no early return can skip it.

**Hold the lock for the shortest possible span, and never across an
await.** The measurement in task 8 is only meaningful if this holds.

A second connect on an established connection is a protocol error;
answer with a reason before closing, since there is a session now.

```rust
use std::sync::Arc;
use std::time::Duration;

use tokio::sync::broadcast;
use tokio::task::JoinHandle;

use crate::shared::Shared;

/// Start the tick that drives every deadline in the broker.
///
/// One task for the whole process. Keep-alive, wills, session expiry and
/// retained expiry all happen because of this and nothing else, so if it
/// stops the broker goes quietly deaf rather than failing loudly.
///
/// The interval is missed rather than burst when the process is
/// descheduled: a tick that arrives late should do one second of work,
/// not catch up on several at once, because the work each one does is
/// idempotent in wall time and catching up would only deepen the stall.
pub fn spawn_ticker(shared: Arc<Shared>, mut shutdown: broadcast::Receiver<()>) -> JoinHandle<()> {
    tokio::spawn(async move {
        let mut interval = tokio::time::interval(Duration::from_secs(1));
        interval.set_missed_tick_behavior(tokio::time::MissedTickBehavior::Skip);
        // The first tick completes immediately; skip it so the clock does
        // not jump a second the moment the process starts.
        interval.tick().await;

        loop {
            tokio::select! {
                _ = interval.tick() => {
                    let actions = shared.with_broker(|broker| {
                        let mut out = Vec::new();
                        broker.tick(&mut out);
                        out
                    });
                    shared.deliver(actions);
                }
                _ = shutdown.recv() => return,
            }
        }
    })
}
```

Write `listener.rs`. The shape:

  rather than by queueing. A queued connection that eventually gets in is
  worse for the client than a prompt refusal it can retry elsewhere.
