# The Broker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Assemble the matching layer and the session state machines into a broker: sessions that connect, disconnect, expire and leave wills; subscriptions that deliver retained messages; publishes that route to the right subscribers; and a keep-alive that scales.

**Architecture:** Still no sockets and no runtime. The broker takes a clock as a parameter rather than reading one, so a test advances time by hand and every outcome is deterministic. The I/O shell is the next plan and is deliberately thin.

**Tech Stack:** Rust, `mqtt-codec` for packet types, `broker-core`'s matching layer and session state machines, `parking_lot` for the registry, `proptest` for the end-to-end properties.

**Spec:** `docs/superpowers/specs/2026-09-19-sd-mqtt-design.md`, sections 5.2, 5.3, 6 and 10.2.

## The idea that makes this plan work

Broker bugs are usually timing bugs, and timing bugs are usually tested by sleeping, which is slow and flaky and proves little.

So **time is a parameter here, not an ambient fact**. Nothing calls the operating system for the time. A coarse clock is advanced explicitly, the keep-alive ring is ticked explicitly, and a will that fires after a thirty second delay is tested by advancing thirty seconds in a microsecond.

That makes the whole broker driveable as a state machine: construct one, feed it packets from imaginary clients, advance the clock, assert. No runtime, no sleeps, no flakes. The end-to-end property in the final task exists because of this, and it is what catches the interactions that no unit test reaches.

## Conventions inherited from three earlier plans

Settled by review and unchanged.

1. **The writer refuses what the reader rejects.** Symmetry between the two directions of any pair.
2. **Assert exact error strings, not error variants.** A test asserting only a variant passes for any other cause of the same variant. This has hidden a real bug twice.
3. **Prove a test has teeth by mutation.** Break the implementation deliberately, confirm that test and only that test fails, restore. Back up with `cp`, not `git checkout --`.
4. **Derive protocol rules from the specification, not this plan.** The plan's statements have been wrong, most seriously when the resume rule omitted that a redelivered publish keeps its original packet identifier, which broke exactly-once delivery. Download the OASIS HTML with `curl` and strip the tags; the Word export splits words across tags so grep alone finds nothing.
5. **Ask what a test structurally cannot reach.** A generator that cannot produce a case leaves that code unguarded while looking covered. This has happened three times.
6. **Beware a harness that mirrors the implementation.** A test that accepts whatever the code accepts cannot catch a wrong acceptance. This is why golden vectors exist in the codec and why the conservation harness has a recorded limitation.

## Three obligations this plan inherits

Recorded at the end of the session state plan, and this is the plan that must honour them.

- **An acknowledgement owed must be paid.** Receiving a publish reserves a receive-maximum slot that only the acknowledgement frees. Drop the result on an error path and the slot never returns, throttling the client silently.
- **Requeueing bypasses the queue's bounds**, deliberately, so a session resumed repeatedly can exceed its byte budget.
- **A receipt for an unknown identifier is answered but not counted.** Answering is correct; a peer can otherwise make the broker emit packets indefinitely with no metric moving.

```rust
use std::sync::atomic::{AtomicU32, Ordering};

/// Whole seconds since an arbitrary origin, advanced explicitly.
///
/// Every deadline in the broker is in whole seconds, and reading the
/// operating system clock per packet would be waste. More importantly,
/// taking time as a parameter rather than reading it makes the whole
/// broker deterministic: a test advances thirty seconds in a microsecond
/// and a will delay is exercised exactly, with no sleeping and no flakes.
///
/// One thread advances it, once a second. Everyone else reads.
pub struct CoarseClock {
    now: AtomicU32,
}

impl CoarseClock {
    /// A clock reading `start`.
    pub fn new(start: u32) -> Self {
        Self {
            now: AtomicU32::new(start),
        }
    }

    /// The current reading.
    ///
    /// Relaxed ordering is deliberate. Readers need a recent value, not a
    /// synchronised one; a deadline that fires a few microseconds late is
    /// indistinguishable from one that fires on a coarse second boundary.
    pub fn now(&self) -> u32 {
        self.now.load(Ordering::Relaxed)
    }

    /// Move forward by `seconds`, returning the new reading.
    pub fn advance(&self, seconds: u32) -> u32 {
        self.now.fetch_add(seconds, Ordering::Relaxed) + seconds
    }

    /// The reading `interval` seconds from now, saturating.
    ///
    /// Saturating matters: a session expiry near the end of the range must
    /// not wrap into the past, which would expire the session the moment
    /// it was created.
    pub fn deadline(&self, interval: u32) -> u32 {
        self.now().saturating_add(interval)
    }
}

impl Default for CoarseClock {
    fn default() -> Self {
        Self::new(0)
    }
}
```

## Task 2: The keep-alive ring

A hundred thousand connections need a hundred thousand deadlines, and a
timer per connection costs both memory and a lock on every packet. The
design spec measured the alternative: a timeout future is 896 bytes, which
is about 90 MB at that scale, and the runtime's timer driver serialises on
one lock that would be taken once per packet.

So instead: one timer for the whole process, a ring of one-second buckets,
and **a packet arrival touches no timer at all**. It performs one relaxed
store of the coarse clock into the connection's activity cell. The sweeper
reads that cell when the cursor reaches the connection's bucket.

```rust
use std::sync::atomic::{AtomicU32, Ordering};
use std::sync::Arc;

use crate::subscriptions::SubscriberId;

/// When a connection was last heard from.
///
/// Shared with the connection so that an arriving packet performs one
/// relaxed store and touches no timer at all. That is the whole reason
/// this is a ring rather than a timer per connection: at a hundred
/// thousand connections, rescheduling a timer per packet means a
/// contended lock per packet.
#[derive(Clone)]
pub struct Activity(Arc<AtomicU32>);

impl Activity {
    /// An activity cell reading `now`.
    pub fn new(now: u32) -> Self {
        Self(Arc::new(AtomicU32::new(now)))
    }

    /// Record that something arrived. One relaxed store, nothing else.
    pub fn touch(&self, now: u32) {
        self.0.store(now, Ordering::Relaxed);
    }

    /// When something last arrived.
    pub fn last(&self) -> u32 {
        self.0.load(Ordering::Relaxed)
    }
}

struct Armed {
    id: SubscriberId,
    /// The negotiated interval in seconds. Zero disables the deadline.
    keep_alive: u16,
    activity: Activity,
}

/// Connections arranged by when they next need checking.
///
/// One timer drives the whole process. Each tick inspects one bucket, so
/// the work per second is the population divided by the number of
/// buckets rather than the whole population.
pub struct KeepAliveRing {
    buckets: Vec<Vec<Armed>>,
    cursor: usize,
    count: usize,
}

/// A client is disconnected after this multiple of its interval.
const LIMIT_NUMERATOR: u32 = 3;
const LIMIT_DENOMINATOR: u32 = 2;

impl KeepAliveRing {
    /// A ring sized for keep-alive intervals up to `max_keep_alive`
    /// seconds. A larger interval still works, by re-arming.
    pub fn new(max_keep_alive: u16) -> Self {
        let slots = (u32::from(max_keep_alive) * LIMIT_NUMERATOR / LIMIT_DENOMINATOR) as usize + 2;
        Self {
            buckets: (0..slots.max(2)).map(|_| Vec::new()).collect(),
            cursor: 0,
            count: 0,
        }
    }

    fn limit(keep_alive: u16) -> u32 {
        u32::from(keep_alive) * LIMIT_NUMERATOR / LIMIT_DENOMINATOR
    }

    /// Arm a connection.
    pub fn insert(&mut self, id: SubscriberId, keep_alive: u16, activity: Activity, now: u32) {
        let armed = Armed {
            id,
            keep_alive,
            activity,
        };
        self.count += 1;
        self.arm(armed, now);
    }

    /// Place a connection in the bucket where it next needs checking.
    fn arm(&mut self, armed: Armed, now: u32) {
        let slots = self.buckets.len();
        if armed.keep_alive == 0 {
            // No deadline. Park it a full revolution away so it is
            // revisited rarely and costs almost nothing.
            let slot = (self.cursor + slots - 1) % slots;
            self.buckets[slot].push(armed);
            return;
        }

        let due = armed.activity.last().saturating_add(Self::limit(armed.keep_alive));
        let ahead = due.saturating_sub(now).max(1) as usize;
        let slot = (self.cursor + ahead.min(slots - 1)) % slots;
        self.buckets[slot].push(armed);
    }

    /// Disarm a connection.
    pub fn remove(&mut self, id: SubscriberId) {
        for bucket in &mut self.buckets {
            let before = bucket.len();
            bucket.retain(|a| a.id != id);
            self.count -= before - bucket.len();
        }
    }

    /// Advance to `now`, appending every connection that has gone quiet
    /// past its limit. Anything still alive is re-armed.
    pub fn tick(&mut self, now: u32, expired: &mut Vec<SubscriberId>) {
        self.cursor = (self.cursor + 1) % self.buckets.len();
        let due = std::mem::take(&mut self.buckets[self.cursor]);

        for armed in due {
            if armed.keep_alive == 0 {
                self.arm(armed, now);
                continue;
            }
            let silent_for = now.saturating_sub(armed.activity.last());
            if silent_for > Self::limit(armed.keep_alive) {
                self.count -= 1;
                expired.push(armed.id);
            } else {
                self.arm(armed, now);
            }
        }
    }

    /// How many connections are armed.
    pub fn len(&self) -> usize {
        self.count
    }

    /// Whether none are.
    pub fn is_empty(&self) -> bool {
        self.count == 0
    }
}
```

## Task 3: Session identity and the registry

A session is identified by its mountpoint and client identifier together.
The mountpoint namespaces a listener's clients into their own topic tree,
which is multi-tenancy for the cost of one string.

The registry is also where **takeover** lives: a connect naming a client
identifier that already has a session claims it, and the previous
connection is closed.

```rust
use std::collections::HashMap;
use std::sync::Arc;

use foldhash::fast::RandomState;

use crate::session::state::Session;
use crate::subscriptions::SubscriberId;

/// What identifies a session.
///
/// The mountpoint namespaces a listener's clients into their own topic
/// tree, so the same client identifier arriving on two listeners is two
/// sessions. That is multi-tenancy for the cost of one string.
#[derive(Debug, Clone, PartialEq, Eq, Hash)]
pub struct SessionId {
    /// The listener's namespace, empty for the default.
    pub mountpoint: Arc<str>,
    /// The identifier the client chose, or one assigned to it.
    pub client_id: Arc<str>,
}

impl SessionId {
    /// Build an identity.
    pub fn new(mountpoint: &str, client_id: &str) -> Self {
        Self {
            mountpoint: Arc::from(mountpoint),
            client_id: Arc::from(client_id),
        }
    }
}

/// The outcome of a connect.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Registration {
    /// The session's handle, which keys its subscriptions.
    pub subscriber: SubscriberId,
    /// Whether state was resumed rather than created. This is what the
    /// acknowledgement's session-present flag reports.
    pub session_present: bool,
    /// Whether a live connection was displaced and must be closed with
    /// "session taken over".
    pub took_over: bool,
    /// The claim's generation. Higher wins.
    pub epoch: u64,
}

/// Sessions by identity.
#[derive(Default)]
pub struct Registry {
    by_identity: HashMap<SessionId, SubscriberId, RandomState>,
    sessions: HashMap<SubscriberId, Session, RandomState>,
    next_subscriber: u64,
    next_epoch: u64,
}

impl Registry {
    /// Claim a session for a connecting client.
    ///
    /// Claiming one that already has a live connection is takeover, not an
    /// error: the protocol says the newcomer wins and the incumbent is
    /// disconnected. The epoch decides who wins if two nodes both accepted
    /// the client during a partition, so it only ever increases.
    pub fn register(&mut self, id: SessionId, clean_start: bool, now: u32) -> Registration {
        self.next_epoch += 1;
        let epoch = self.next_epoch;

        if let Some(subscriber) = self.by_identity.get(&id).copied() {
            let existing = self
                .sessions
                .get_mut(&subscriber)
                .expect("the index and the map agree");
            let took_over = existing.is_connected();

            if clean_start {
                let version = existing.version();
                *existing = Session::new(id, subscriber, version, epoch, now);
                return Registration {
                    subscriber,
                    session_present: false,
                    took_over,
                    epoch,
                };
            }

            existing.claim(epoch, now);
            return Registration {
                subscriber,
                session_present: true,
                took_over,
                epoch,
            };
        }

        // A handle is never reused, because the subscription trie is keyed
        // by it and reuse would hand one session another's subscriptions.
        let subscriber = SubscriberId(self.next_subscriber);
        self.next_subscriber += 1;
        self.by_identity.insert(id.clone(), subscriber);
        self.sessions.insert(
            subscriber,
            Session::new(id, subscriber, crate::session::state::DEFAULT_VERSION, epoch, now),
        );

        Registration {
            subscriber,
            session_present: false,
            took_over: false,
            epoch,
        }
    }

    /// Note that a session's connection went away.
    pub fn disconnect(&mut self, subscriber: SubscriberId, now: u32) {
        if let Some(session) = self.sessions.get_mut(&subscriber) {
            session.on_disconnected(true, now);
        }
    }

    /// A session by handle.
    pub fn get(&self, subscriber: SubscriberId) -> Option<&Session> {
        self.sessions.get(&subscriber)
    }

    /// A session by handle, mutably.
    pub fn get_mut(&mut self, subscriber: SubscriberId) -> Option<&mut Session> {
        self.sessions.get_mut(&subscriber)
    }

    /// The handle for an identity.
    pub fn subscriber_of(&self, id: &SessionId) -> Option<SubscriberId> {
        self.by_identity.get(id).copied()
    }

    /// Destroy a session.
    pub fn remove(&mut self, subscriber: SubscriberId) -> Option<Session> {
        let session = self.sessions.remove(&subscriber)?;
        self.by_identity.remove(session.id());
        Some(session)
    }

    /// Every session, mutably, for a sweep.
    pub fn iter_mut(&mut self) -> impl Iterator<Item = (&SubscriberId, &mut Session)> {
        self.sessions.iter_mut()
    }

    /// How many sessions exist, connected or not.
    pub fn len(&self) -> usize {
        self.sessions.len()
    }

    /// Whether none do.
    pub fn is_empty(&self) -> bool {
        self.sessions.is_empty()
    }
}
```

```rust
use bytes::Bytes;
use mqtt_codec::{QoS, ReasonCode, Version};

use crate::registry::SessionId;
use crate::session::inbound::Inbound;
use crate::session::outbound::Outbound;
use crate::session::queue::QueueLimits;
use crate::subscriptions::SubscriberId;

/// The version assumed before a connect has been decoded.
pub const DEFAULT_VERSION: Version = Version::V311;

/// A message published on the client's behalf if it disappears.
#[derive(Debug, Clone)]
pub struct StoredWill {
    /// Where to publish it.
    pub topic: String,
    /// What to publish.
    pub payload: Bytes,
    /// At what level.
    pub qos: QoS,
    /// Whether to retain it.
    pub retain: bool,
    /// Seconds to wait first. MQTT 5 only; a brief outage should not
    /// announce a device as gone.
    pub delay: u32,
}

/// One client's session, connected or not.
pub struct Session {
    id: SessionId,
    subscriber: SubscriberId,
    version: Version,
    epoch: u64,
    connected: bool,
    /// The outbound path, which outlives the connection.
    pub outbound: Outbound,
    /// The inbound path.
    pub inbound: Inbound,
    /// Filters this session holds, so teardown can undo them.
    filters: Vec<String>,
    will: Option<StoredWill>,
    /// When the will becomes due, if it is owed.
    will_at: Option<u32>,
    expiry_interval: u32,
    /// When the session may be destroyed, once disconnected.
    expires_at: Option<u32>,
}

impl Session {
    /// A fresh session, connected.
    ///
    /// The outbound path is put online here rather than left for a later
    /// call, so the session cannot report itself connected while silently
    /// discarding every fire-and-forget delivery offered to it.
    pub fn new(
        id: SessionId,
        subscriber: SubscriberId,
        version: Version,
        epoch: u64,
        _now: u32,
    ) -> Self {
        Self {
            id,
            subscriber,
            version,
            epoch,
            connected: true,
            outbound: {
                let mut outbound = Outbound::new(QueueLimits::default(), 20);
                outbound.set_online(true);
                outbound
            },
            inbound: Inbound::new(0),
            filters: Vec::new(),
            will: None,
            will_at: None,
            expiry_interval: 0,
            expires_at: None,
        }
    }

    /// Reclaim an existing session for a new connection.
    ///
    /// Cancels any owed will: the client came back, so it was never gone.
    pub fn claim(&mut self, epoch: u64, _now: u32) {
        self.epoch = epoch;
        self.connected = true;
        self.will_at = None;
        self.expires_at = None;
        self.outbound.set_online(true);
    }

    /// The connection went away.
    ///
    /// A graceful departure discards the will; an abrupt one owes it,
    /// after the delay in MQTT 5 and at once in 3.1.1.
    pub fn on_disconnected(&mut self, graceful: bool, now: u32) {
        self.connected = false;
        self.outbound.on_disconnect();
        self.inbound.on_disconnect();

        if graceful {
            self.will = None;
            self.will_at = None;
        } else if self.will.is_some() {
            let delay = if self.version == Version::V5 {
                self.delay_capped_by_expiry()
            } else {
                0
            };
            self.will_at = Some(now.saturating_add(delay));
        }

        self.expires_at = Some(now.saturating_add(self.expiry_interval));
    }

    /// A disconnect packet arrived.
    ///
    /// In MQTT 5 only a normal disconnection discards the will. Any other
    /// reason, including one asking for the will explicitly, leaves it
    /// owed: a client reporting a protocol error is still gone
    /// unexpectedly as far as its subscribers are concerned. MQTT 3.1.1
    /// has no reason code, so any disconnect packet discards it.
    pub fn on_disconnect_packet(&mut self, reason: ReasonCode, now: u32) {
        let wants_will = self.version == Version::V5 && reason != ReasonCode::Success;
        self.on_disconnected(!wants_will, now);
    }

    /// A delay longer than the session lives is pointless, because the
    /// will falls due when the session ends, whichever comes first.
    ///
    /// An expiry of zero is the important case rather than an exception:
    /// the session ends when the connection closes, so the will is owed
    /// at once no matter what delay was asked for.
    fn delay_capped_by_expiry(&self) -> u32 {
        self.will
            .as_ref()
            .map_or(0, |will| will.delay.min(self.expiry_interval))
    }

    /// Take the will if it is due, leaving nothing behind.
    pub fn take_due_will(&mut self, now: u32) -> Option<StoredWill> {
        match self.will_at {
            Some(due) if now >= due => {
                self.will_at = None;
                self.will.take()
            }
            _ => None,
        }
    }

    /// Set or clear the will.
    pub fn set_will(&mut self, will: Option<StoredWill>) {
        self.will = will;
    }

    /// How long the session outlives its connection.
    pub fn set_expiry_interval(&mut self, seconds: u32) {
        self.expiry_interval = seconds;
    }

    /// Whether the session may be destroyed. A connected one never may.
    pub fn is_expired(&self, now: u32) -> bool {
        !self.connected && self.expires_at.is_some_and(|at| now >= at)
    }

    /// Record a filter this session holds.
    pub fn add_filter(&mut self, filter: &str) {
        if !self.filters.iter().any(|f| f == filter) {
            self.filters.push(filter.to_string());
        }
    }

    /// Forget a filter.
    pub fn remove_filter(&mut self, filter: &str) -> bool {
        let before = self.filters.len();
        self.filters.retain(|f| f != filter);
        self.filters.len() != before
    }

    /// Every filter this session holds.
    pub fn filters(&self) -> impl Iterator<Item = &str> {
        self.filters.iter().map(String::as_str)
    }

    /// Whether a connection is attached.
    pub fn is_connected(&self) -> bool {
        self.connected
    }

    /// Which protocol version the client speaks.
    pub fn version(&self) -> Version {
        self.version
    }

    /// Record the version once the connect has been decoded.
    pub fn set_version(&mut self, version: Version) {
        self.version = version;
    }

    /// The claim's generation.
    pub fn epoch(&self) -> u64 {
        self.epoch
    }

    /// This session's identity.
    pub fn id(&self) -> &SessionId {
        &self.id
    }

    /// The handle keying its subscriptions.
    pub fn subscriber(&self) -> SubscriberId {
        self.subscriber
    }
}

/// Turn a stored will into a message to publish.
pub fn will_message(will: &StoredWill) -> crate::session::message::Message {
    crate::session::message::Message::new(
        &will.topic,
        will.payload.clone(),
        will.qos,
        will.retain,
    )
}
```

```rust
use mqtt_codec::packet::{RetainHandling, Subscribe};
use mqtt_codec::{Limits, QoS, ReasonCode};

use crate::retained::RetainedStore;
use crate::session::message::Message;
use crate::session::queue::Delivery;
use crate::session::state::Session;
use crate::session::Action;
use crate::subscriptions::{SharedSubscriptions, Subscription, SubscriptionTrie};

/// Apply a subscribe request, returning one reason code per filter.
///
/// A bad filter refuses only itself: the protocol answers per filter, and
/// refusing the whole packet would punish the good ones.
pub fn subscribe(
    trie: &SubscriptionTrie,
    shared: &SharedSubscriptions,
    retained: &RetainedStore,
    session: &mut Session,
    packet: &Subscribe,
    limits: &Limits,
    now: u32,
    out: &mut Vec<Action>,
) -> Vec<ReasonCode> {
    let subscription_id = packet.properties.subscription_identifiers.first().copied();
    let mut reasons = Vec::with_capacity(packet.filters.len());

    for options in &packet.filters {
        let group = match mqtt_codec::topic::validate_subscription(&options.filter, limits) {
            Ok(group) => group,
            Err(_) => {
                reasons.push(ReasonCode::TopicFilterInvalid);
                continue;
            }
        };

        let subscription = Subscription {
            subscriber: session.subscriber(),
            qos: options.qos,
            no_local: options.no_local,
            retain_as_published: options.retain_as_published,
            id: subscription_id,
        };

        let existed = match group {
            Some((name, inner)) => shared.insert(name, inner, subscription),
            None => trie.insert(&options.filter, subscription),
        };
        session.add_filter(&options.filter);

        // A shared subscription has no single subscriber to hand retained
        // messages to, so it receives none.
        let wants_retained = group.is_none()
            && match options.retain_handling {
                RetainHandling::SendAlways => true,
                RetainHandling::SendIfNew => !existed,
                RetainHandling::DoNotSend => false,
            };

        if wants_retained {
            deliver_retained(
                retained,
                session,
                &options.filter,
                options,
                subscription_id,
                now,
                out,
            );
        }

        reasons.push(match options.qos {
            QoS::AtMostOnce => ReasonCode::Success,
            QoS::AtLeastOnce => ReasonCode::GrantedQos1,
            QoS::ExactlyOnce => ReasonCode::GrantedQos2,
        });
    }

    reasons
}

fn deliver_retained(
    retained: &RetainedStore,
    session: &mut Session,
    filter: &str,
    options: &mqtt_codec::packet::SubscriptionOptions,
    subscription_id: Option<u32>,
    now: u32,
    out: &mut Vec<Action>,
) {
    let mut matches = Vec::new();
    retained.matching(filter, now, &mut matches);

    for (topic, kept) in matches {
        let qos = options.qos.min(kept.qos);
        let mut message = Message::new(&topic, kept.payload, kept.qos, true);
        message.expires_at = kept.expires_at;

        session.outbound.offer(
            Delivery {
                message,
                qos,
                // A retained delivery always says so, whatever the
                // retain-as-published option says: that option is about
                // live messages.
                retain: true,
                dup: false,
                packet_id: None,
                subscription_ids: subscription_id.into_iter().collect(),
            },
            now,
            out,
        );
    }
}

/// Remove filters, returning one reason code each.
pub fn unsubscribe(
    trie: &SubscriptionTrie,
    shared: &SharedSubscriptions,
    session: &mut Session,
    filters: &[String],
) -> Vec<ReasonCode> {
    filters
        .iter()
        .map(|filter| {
            let removed = match mqtt_codec::topic::parse_shared(filter) {
                Ok(Some((name, inner))) => shared.remove(name, inner, session.subscriber()),
                _ => trie.remove(filter, session.subscriber()),
            };
            session.remove_filter(filter);
            if removed {
                ReasonCode::Success
            } else {
                ReasonCode::NoSubscriptionExisted
            }
        })
        .collect()
}

/// Remove every subscription a session holds, for teardown.
pub fn remove_all(trie: &SubscriptionTrie, shared: &SharedSubscriptions, session: &mut Session) {
    trie.remove_subscriber(session.subscriber());
    shared.remove_subscriber(session.subscriber());
    let held: Vec<String> = session.filters().map(str::to_string).collect();
    for filter in held {
        session.remove_filter(&filter);
    }
}
```

## Task 6: Publish routing

Where a message becomes zero or more deliveries. Three rules here are
each a place brokers get wrong.

**A subscriber holding two matching filters gets one message, not two.**
The routing core returns one entry per subscription and its reviewer

caller. The single delivery carries the highest granted level and every
matching subscription identifier.

**No-local is about the publisher, not the topic.** A subscriber that
set it does not receive its own publications.

**Retained is a side effect, not a delivery.** A message with the retain
flag updates the store and is also delivered normally; an empty payload
clears the store instead.

```rust
use mqtt_codec::QoS;

use crate::session::message::Message;
use crate::subscriptions::{SharedSubscriptions, SubscriberId, Subscription, SubscriptionTrie};

/// One message addressed to one subscriber.
#[derive(Debug, Clone)]
pub struct Routed {
    /// Who receives it.
    pub subscriber: SubscriberId,
    /// At what level, the lesser of published and granted.
    pub qos: QoS,
    /// The retain flag as it goes on the wire.
    pub retain: bool,
    /// Every matching subscription's identifier, for MQTT 5.
    pub subscription_ids: Vec<u32>,
}

/// Turn one publication into deliveries.
///
/// A subscriber holding several matching filters receives **one**
/// message, at the highest level any of them granted, carrying every
/// matching subscription identifier. The matching layer returns one entry
/// per subscription, so merging them is this function's job.
///
/// `publisher` withholds the message from any subscription that set
/// no-local, which is about who sent it rather than what it says.
pub fn route(
    trie: &SubscriptionTrie,
    shared: &SharedSubscriptions,
    message: &Message,
    publisher: Option<SubscriberId>,
    out: &mut Vec<Routed>,
) {
    let mut matched = Vec::new();
    trie.matching(&message.topic[..], &mut matched);

    for subscription in matched {
        if is_withheld(&subscription, publisher) {
            continue;
        }
        merge(out, &subscription, message);
    }

    // A shared group contributes one member, and that member is merged
    // like any other: a client holding both an ordinary and a shared
    // subscription to the same topic still receives one message.
    let mut chosen = Vec::new();
    shared.select(&message.topic[..], &mut chosen);
    for subscription in chosen {
        if is_withheld(&subscription, publisher) {
            continue;
        }
        merge(out, &subscription, message);
    }
}

fn is_withheld(subscription: &Subscription, publisher: Option<SubscriberId>) -> bool {
    subscription.no_local && publisher == Some(subscription.subscriber)
}

fn merge(out: &mut Vec<Routed>, subscription: &Subscription, message: &Message) {
    let qos = subscription.qos.min(message.qos);
    let retain = subscription.retain_as_published && message.retain;

    if let Some(existing) = out
        .iter_mut()
        .find(|r| r.subscriber == subscription.subscriber)
    {
        existing.qos = existing.qos.max(qos);
        // Retain-as-published on any matching subscription is enough:
        // the flag describes the message, and withholding it would lose
        // information the subscriber asked for.
        existing.retain |= retain;
        // Duplicates are expected, not a mistake to filter. One subscribe
        // packet gives every filter in it the same identifier, so a client
        // subscribing to two overlapping filters at once must see that
        // identifier twice: it says two of its subscriptions matched.
        existing.subscription_ids.extend(subscription.id);
        return;
    }

    out.push(Routed {
        subscriber: subscription.subscriber,
        qos,
        retain,
        subscription_ids: subscription.id.into_iter().collect(),
    });
}
```

```rust
    clock: Arc<CoarseClock>,
    subscriptions: SubscriptionTrie,
    shared: SharedSubscriptions,
    retained: RetainedStore,
    registry: Registry,
    keepalive: KeepAliveRing,
    activities: HashMap<SubscriberId, Activity, RandomState>,
    config: BrokerConfig,
}

impl Broker {
    /// A broker with no sessions, its clock at zero.
    pub fn new(config: BrokerConfig) -> Self {
        Self {
            clock: Arc::new(CoarseClock::new(0)),
            subscriptions: SubscriptionTrie::new(config.trie_shards),
            shared: SharedSubscriptions::new(config.trie_shards),
            retained: RetainedStore::new(),
            registry: Registry::default(),
            keepalive: KeepAliveRing::new(config.max_keep_alive),
            activities: HashMap::with_hasher(RandomState::default()),
            config,
        }
    }

    /// The clock, so the shell can advance it and a test can read it.
    pub fn clock(&self) -> &Arc<CoarseClock> {
        &self.clock
    }

    /// Accept a connection.
    ///
    /// Taking over a session that already has a live connection is not an
    /// error: the newcomer wins and the incumbent is told why.
    pub fn connect(
        &mut self,
        mountpoint: &str,
        connect: &Connect,
        out: &mut Vec<Addressed>,
    ) -> Registration {
        let now = self.clock.now();
        let identity = SessionId::new(mountpoint, &connect.client_id);
        let registration = self.registry.register(identity, connect.clean_start, now);

        if registration.took_over {
            out.push((
                registration.subscriber,
                Action::Close(ReasonCode::SessionTakenOver),
            ));
        }

        let session = self
            .registry
            .get_mut(registration.subscriber)
            .expect("just registered");
        session.set_version(connect.version);
        session.set_expiry_interval(
            connect
                .properties
                .session_expiry_interval
                .unwrap_or_default(),
        );
        session.set_will(connect.will.as_ref().map(|will| StoredWill {
            topic: will.topic.clone(),
            payload: will.payload.clone(),
            qos: will.qos,
            retain: will.retain,
            delay: will.properties.will_delay_interval.unwrap_or_default(),
        }));

        let mut actions = Vec::new();
        session.outbound.on_resume(now, &mut actions);
        for action in actions {
            out.push((registration.subscriber, action));
        }

        let activity = Activity::new(now);
        self.activities.insert(registration.subscriber, activity.clone());
        self.keepalive
            .insert(registration.subscriber, connect.keep_alive, activity, now);

        registration
    }

    /// Handle a packet from a connected client.
    ///
    /// An error is the reason to close the connection with; the caller
    /// does the closing.
    pub fn handle(
        &mut self,
        subscriber: SubscriberId,
        packet: &Packet,
        out: &mut Vec<Addressed>,
    ) -> Result<(), ReasonCode> {
        let now = self.clock.now();
        if let Some(activity) = self.activities.get(&subscriber) {
            // The only thing an arriving packet does to the keep-alive
            // machinery: one relaxed store, no timer, no lock.
            activity.touch(now);
        }

        match packet {
            Packet::Publish(publish) => self.on_publish(subscriber, publish, now, out),
            Packet::Subscribe(request) => {
                let mut actions = Vec::new();
                let session = self
                    .registry
                    .get_mut(subscriber)
                    .ok_or(ReasonCode::ProtocolError)?;
                let reasons = subscribe::subscribe(
                    &self.subscriptions,
                    &self.shared,
                    &self.retained,
                    session,
                    request,
                    &self.config.limits,
                    now,
                    &mut actions,
                );
                actions.push(Action::Send(Packet::SubAck(mqtt_codec::packet::SubAck {
                    packet_id: request.packet_id,
                    reasons,
                    properties: Default::default(),
                })));
                for action in actions {
                    out.push((subscriber, action));
                }
                Ok(())
            }
            Packet::Unsubscribe(request) => {
                let session = self
                    .registry
                    .get_mut(subscriber)
                    .ok_or(ReasonCode::ProtocolError)?;
                let reasons =
                    subscribe::unsubscribe(&self.subscriptions, &self.shared, session, &request.filters);
                out.push((
                    subscriber,
                    Action::Send(Packet::UnsubAck(mqtt_codec::packet::UnsubAck {
                        packet_id: request.packet_id,
                        reasons,
                        properties: Default::default(),
                    })),
                ));
                Ok(())
            }
            Packet::PingReq => {
                out.push((subscriber, Action::Send(Packet::PingResp)));
                Ok(())
            }
            Packet::Disconnect(disconnect) => {
                self.disconnect_with(subscriber, disconnect.reason, now, out);
                Ok(())
            }
            other => self.on_acknowledgement(subscriber, other, now, out),
        }
    }

    fn on_acknowledgement(
        &mut self,
        subscriber: SubscriberId,
        packet: &Packet,
        now: u32,
        out: &mut Vec<Addressed>,
    ) -> Result<(), ReasonCode> {
        let mut actions = Vec::new();
        let session = self
            .registry
            .get_mut(subscriber)
            .ok_or(ReasonCode::ProtocolError)?;

        let result = match packet {
            Packet::PubAck(ack) => {
                session
                    .outbound
                    .on_puback(ack.packet_id, ack.reason, now, &mut actions)
            }
            Packet::PubRec(ack) => {
                session
                    .outbound
                    .on_pubrec(ack.packet_id, ack.reason, now, &mut actions)
            }
            Packet::PubComp(ack) => session.outbound.on_pubcomp(ack.packet_id, now, &mut actions),
            Packet::PubRel(ack) => {
                session.inbound.on_pubrel(ack.packet_id, &mut actions);
                Ok(())
            }
            _ => Err(ReasonCode::ProtocolError),
        };

        for action in actions {
            out.push((subscriber, action));
        }
        result
    }

    fn on_publish(
        &mut self,
        from: SubscriberId,
        publish: &mqtt_codec::packet::Publish,
        now: u32,
        out: &mut Vec<Addressed>,
    ) -> Result<(), ReasonCode> {
        let mut actions = Vec::new();
        let received = {
            let session = self
                .registry
                .get_mut(from)
                .ok_or(ReasonCode::ProtocolError)?;
            session.inbound.on_publish(publish, &mut actions)?
        };
        for action in actions {
            out.push((from, action));
        }

        if !received_wants_dispatch(&received) {
            return Ok(());
        }

        let mut message = Message::new(
            &publish.topic,
            publish.payload.clone(),
            publish.qos,
            publish.retain,
        );
        message.properties = Arc::new(publish.properties.clone());
        message.expires_at = publish
            .properties
            .message_expiry_interval
            .map(|interval| self.clock.deadline(interval));

        let delivered = self.publish(message, Some(from), now, out);

        // The acknowledgement is owed until now, because whether anyone
        // wanted the message is only known after routing.
        self.acknowledge(from, publish, delivered, now, out);
        Ok(())
    }

    fn acknowledge(
        &mut self,
        subscriber: SubscriberId,
        publish: &mqtt_codec::packet::Publish,
        delivered: usize,
        _now: u32,
        out: &mut Vec<Addressed>,
    ) {
        let Some(packet_id) = publish.packet_id else {
            return;
        };
        let reason = if delivered == 0 {
            ReasonCode::NoMatchingSubscribers
        } else {
            ReasonCode::Success
        };

        let mut actions = Vec::new();
        if let Some(session) = self.registry.get_mut(subscriber) {
            session
                .inbound
                .acknowledge(packet_id, publish.qos, reason, &mut actions);
        }
        for action in actions {
            out.push((subscriber, action));
        }
    }

    /// Route a message to every subscriber that wants it, updating the
    /// retained store first when the flag is set. Returns how many
    /// subscribers it reached.
    pub fn publish(
        &mut self,
        message: Message,
        publisher: Option<SubscriberId>,
        now: u32,
        out: &mut Vec<Addressed>,
    ) -> usize {
        if message.retain {
            // An empty payload clears the topic rather than storing one.
            self.retained.set(
                &message.topic,
                RetainedMessage {
                    payload: message.payload.clone(),
                    qos: message.qos,
                    expires_at: message.expires_at,
                },
            );
        }

        let mut routed = Vec::new();
        route::route(&self.subscriptions, &self.shared, &message, publisher, &mut routed);
        let reached = routed.len();

        for target in routed {
            let mut actions = Vec::new();
            if let Some(session) = self.registry.get_mut(target.subscriber) {
                session.outbound.offer(
                    Delivery {
                        message: message.clone(),
                        qos: target.qos,
                        retain: target.retain,
                        dup: false,
                        packet_id: None,
                        subscription_ids: target.subscription_ids,
                    },
                    now,
                    &mut actions,
                );
            }
            for action in actions {
                out.push((target.subscriber, action));
            }
        }

        reached
    }

    /// A connection went away without a disconnect packet.
    pub fn disconnect(&mut self, subscriber: SubscriberId, out: &mut Vec<Addressed>) {
        let now = self.clock.now();
        self.detach(subscriber, false, now, out);
    }

    fn disconnect_with(
        &mut self,
        subscriber: SubscriberId,
        reason: ReasonCode,
        now: u32,
        out: &mut Vec<Addressed>,
    ) {
        let graceful = reason != ReasonCode::DisconnectWithWillMessage;
        self.detach(subscriber, graceful, now, out);
    }

    fn detach(
        &mut self,
        subscriber: SubscriberId,
        graceful: bool,
        now: u32,
        _out: &mut Vec<Addressed>,
    ) {
        self.keepalive.remove(subscriber);
        self.activities.remove(&subscriber);
        if let Some(session) = self.registry.get_mut(subscriber) {
            session.on_disconnected(graceful, now);
        }
    }

    /// Advance one second and do everything that falls due.
    pub fn tick(&mut self, out: &mut Vec<Addressed>) {
        let now = self.clock.advance(1);

        let mut expired = Vec::new();
        self.keepalive.tick(now, &mut expired);
        for subscriber in expired {
            out.push((subscriber, Action::Close(ReasonCode::KeepAliveTimeout)));
            self.detach(subscriber, false, now, &mut Vec::new());
        }

        // Wills first: a session that expires this tick may also owe one.
        let due: Vec<(SubscriberId, StoredWill)> = self
            .registry
            .iter_mut()
            .filter_map(|(id, session)| session.take_due_will(now).map(|will| (*id, will)))
            .collect();
        for (publisher, will) in due {
            let message = will_message(&will);
            self.publish(message, Some(publisher), now, out);
        }

        let gone: Vec<SubscriberId> = self
            .registry
            .iter_mut()
            .filter(|(_, session)| session.is_expired(now))
            .map(|(id, _)| *id)
            .collect();
        for subscriber in gone {
            if let Some(mut session) = self.registry.remove(subscriber) {
                subscribe::remove_all(&self.subscriptions, &self.shared, &mut session);
            }
            self.keepalive.remove(subscriber);
            self.activities.remove(&subscriber);
        }

        self.retained.sweep_expired(now);
    }

    /// How many sessions exist, connected or not.
    pub fn session_count(&self) -> usize {
        self.registry.len()
    }

    /// How many subscriptions are held, for a metric and for tests.
    pub fn subscription_count(&self) -> usize {
        self.subscriptions.len() + self.shared.member_count()
    }
}
```

```rust
fn received(out: &[(SubscriberId, Action)], topic: &str) -> HashMap<SubscriberId, usize> {
    let mut counts = HashMap::new();
    for (subscriber, action) in out {
        if let Action::Send(Packet::Publish(publish)) = action {
            if publish.topic == topic {
                *counts.entry(*subscriber).or_insert(0) += 1;
```
